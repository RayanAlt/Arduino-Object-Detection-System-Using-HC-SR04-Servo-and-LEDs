# Arduino-Object-Detection-System-Using-HC-SR04-Servo-and-LEDs

his project uses an Arduino, HC-SR04 ultrasonic sensor, servo motor, and two LEDs to detect objects.

When an object is 10 cm or closer, the green LED turns on and the servo moves to 90°.

When the object is farther than 10 cm, the red LED turns on and the servo returns to 0°.

The distance is also displayed in the Serial Monitor.
--------------------------------------------------------------------------------------------

Components

Arduino board

HC-SR04 ultrasonic sensor

Servo motor

Green LED

Red LED

2 × 220Ω resistors

Breadboard

Jumper wires


--------------------------------------------------------
Pin Setup

HC-SR04 Trig → 6

HC-SR04 Echo → 7

Servo → 9

Green LED → 2

Red LED → 4

------------------------------------------------------
Object ≤ 10 cm: 🟢 Green LED + Servo at 90°

Object > 10 cm: 🔴 Red LED + Servo at 0°
